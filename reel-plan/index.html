Why this model works for the at-home customer, not just creators

Look at what @shopfirsthealth actually asks for: nothing except an email and a first order. No follower count, no application, no portfolio. A normal customer can take that offer and never post a thing.

The affiliate part happens after she buys and tags us. So the model converts a home customer into a customer first, and into an affiliate second — which is exactly the order we want. Nothing about it needs to be changed for our audience.

Neither reel names a product, and neither DM does either — "our Summer Sale", "your own Cooldown gear". This mechanic is brand-level, so ours is too. The video shows a curler, a dryer, brushes; the offer is about HOLLA.

02

The plan — nine runs

⚠ Trial Reels — not normal Reels. Every single one.

A Trial Reel goes only to people who don't follow us. That's the entire point: this is for strangers, and our own followers aren't the audience. It also gives each run a fresh, clean sample — which is what makes them comparable.

If one goes up as a normal Reel by mistake, that run is void. Don't count it, don't compare it.

Each Trial Reel is one creative paired with one DM flow. We work through every pairing, one every day or two.

Every creative meets every flow exactly once. So at the end it reads two ways — average creative A's three runs to see how A did, average flow 1's three runs to see how flow 1 did. Same nine reels, two answers.

The rules while it runs

  • One live at a time. Post the next once the last has had at least 24 hours.
  • Roshan picks the video for every run. Free choice — different footage each time is better than the same clip nine times, and the platform prefers it too. Show the curler, the dryer, the brushes — a home-user result.
  • Log every run before the next goes up: run, creative, flow, date, views, likes, comments, DMs sent, emails captured, orders, affiliate sign-ups.
  • Kill anything under 0.3 comments per like. Note it and move on.
  • Anything over 1.0 is a winner — stop the rotation and run that combination properly.

05

The three ManyChat flows

Copied

All three trigger on SALON in a comment on that specific Trial Reel, and all three post a short public reply in the thread too — that's another comment on the post, and it's free.

⚠ Ask for the follow. Never block on it.

If she doesn't follow us, put this line at the top of the first message and send the message anyway:

"Quick thing — follow @hollahair.pro so my messages reach you instead of landing in your requests folder 🤍"

@cocolifestyleresort's automation never replied to us, across two attempts, one as a follower. Their reel has 20,800 comments. Twenty thousand people raised their hand and nobody caught them. We don't repeat that.

What the three are testing

1 vs 3 — what the email ask costs, in orders. 1 vs 2 — does a conversation with a button beat one straight message. 2 vs 1 and 3 — does leading with the affiliate program beat leading with the discount.

Every captured email goes to one dedicated Klaviyo list, so we can see which flow filled it fastest.

06

Before the first one goes up

The affiliate side already exists

HOLLA already runs an affiliate program — 10% commission, through UpPromote in Shopify. So the second half of every flow above describes something real. Nothing to invent.

The technical part — the sign-up page, how the code gets issued, whether it's automatic or Roshan does it by hand — we deal with at the end. For the first runs Roshan can set each person up manually; at these volumes that's fine, and it tells us whether anyone actually wants it before we wire anything.

The one number you need to set

The welcome discount, [XX]%. Theirs is 40% on top of a 70% sale. What we can afford: the crimper and curlers run about 73% margin, the dryers 78–81%, brush bundles 55–62%. So even 30% leaves a healthy contribution on tools, and 40% is survivable on the dryers.

⚠ But "valid for 72 hrs" only works if it's true

We still have two permanent 10% codes with no expiry — HAIRPOWER and STYLISTPOWER (302 uses, out in the world). A welcome code that "expires in 72 hours" isn't credible while a 10% code sits on our site forever and one search proves it. That decision is still open from the September sync, and this funnel needs it closed.
